AI MASTER - النسخة التأسيسية

ماذا تحتوي؟
- واجهة عربية RTL متوافقة مع الهاتف.
- صفحات الصور والفيديو والتعديل والشخصيات والمعرض.
- حفظ أوصاف الصور والفيديو والشخصيات محلياً في المتصفح.
- اختيار صورة ومعاينتها.
- إعداد PWA أولي للتثبيت من المتصفح.

مهم:
هذه ليست منصة توليد ذكاء اصطناعي مكتملة بعد.
لا يوجد اتصال بمحرك صور أو فيديو أو قاعدة بيانات سحابية.
البيانات الحالية تحفظ محلياً في المتصفح، وقد تضيع عند مسح بياناته.
لا تضع مفاتيح API داخل ملفات الواجهة أو المستودع العام.

طريقة التجربة:
1) ارفع ملفات هذا المجلد إلى Replit أو محرر استضافة يدعم مواقع HTML.
2) شغّل الموقع عبر HTTPS.
3) افتح رابط الموقع على Android باستخدام Chrome.
4) من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق" إن ظهر الخيار.

المرحلة التالية:
- إعداد قاعدة بيانات خاصة ومصادقة مستخدم.
- إعداد تخزين خاص للصور والفيديو.
- إنشاء backend آمن لربط مزود توليد صور وفيديو.
- اختيار مزود مجاني/محلي أو GPU سحابي، مع إظهار حدود التكلفة قبل كل عملية.
- إضافة حفظ مرجع الشخصية والاتساق البصري عبر النموذج المختار.

الخصوصية والسلامة:
اجعل الحساب خاصاً، ولا تسمح إلا بمحتوى قانوني لشخصيات خيالية بالغة.
لا ترفع صور أشخاص حقيقيين دون موافقتهم.
